# Common Data & REST API Contract

This document defines the **single source of truth** for all JSON data structures and REST API endpoints used across the backend and frontend. Every team member must adhere strictly to these models to ensure zero integration errors.

---

## 1. Common Data Structures

### 1.1 The Core Transaction Model
All six members and all services **MUST** use this exact format for cryptocurrency transactions.

```json
{
  "hash": "0x1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b",
  "from": "0x71C836643F37711fa49b560Ab95360E6533c7F9E",
  "to": "0x98A53B25C653C8D06Ac859bC7d995F4D3C0123AB",
  "amount": 2.50,
  "asset": "ETH",
  "timestamp": "2026-09-02T10:30:00Z"
}
```

#### Field Descriptions:
| Field | Type | Required | Description | Example |
| :--- | :--- | :--- | :--- | :--- |
| `hash` | String | Yes | Unique 66-character hexadecimal Ethereum transaction hash | `"0x1a2b...9e0f"` |
| `from` | String | Yes | Sender wallet address (42-char hex string starting with `0x`) | `"0x71C8...7F9E"` |
| `to` | String | Yes | Recipient wallet address (42-char hex string starting with `0x`) | `"0x98A5...23AB"` |
| `amount` | Number | Yes | Value transferred in native token units (float/double) | `2.50` |
| `asset` | String | Yes | Token/currency ticker symbol | `"ETH"` |
| `timestamp` | String | Yes | ISO-8601 UTC timestamp of block inclusion | `"2026-09-02T10:30:00Z"` |

## 2. REST API Endpoints

### 2.1 Get Wallet Transactions
- **Endpoint:** `GET /api/wallet/{address}/transactions`
- **Purpose:** Retrieves all on-chain transactions for a target wallet.
- **Path Parameter:** `address` (e.g. `0x71C8...`)
- **Query Parameter (Optional):** `limit` (default: 50)
- **Response `200 OK`:** Array of `Transaction` objects.

#### Example Request:
```bash
curl -X GET http://localhost:8080/api/wallet/0x71C836643F37711fa49b560Ab95360E6533c7F9E/transactions
```

---

### 2.2 Analyze Wallet Risk
- **Endpoint:** `POST /api/risk/analyze`
- **Purpose:** Calculates heuristic risk score and triggered indicators for a given transaction set or wallet.
- **Request Body:**
```json
{
  "address": "0x71C836643F37711fa49b560Ab95360E6533c7F9E"
}
```
- **Response `200 OK`:** `RiskResult` object.

---

### 2.3 Trace Funds (Graph Generator)
- **Endpoint:** `POST /api/funds/trace`
- **Purpose:** Traces incoming and outgoing hops to build the directed Cytoscape graph.
- **Request Body:**
```json
{
  "address": "0x71C836643F37711fa49b560Ab95360E6533c7F9E",
  "maxHops": 3
}
```
- **Response `200 OK`:** `FundFlowGraph` object.

---

### 2.4 Check VASP Identification
- **Endpoint:** `POST /api/vasp/check`
- **Purpose:** Checks an address against the fictional VASP database and determines if it is the Last Traceable Point.
- **Request Body:**
```json
{
  "address": "0xVASP_APEX_DEPOSIT_888"
}
```
- **Response `200 OK`:** `VaspCheckResult` object.

---

### 2.5 Generate AI Investigation Explanation
- **Endpoint:** `POST /api/investigation/explain`
- **Purpose:** Synthesizes the risk indicators and transaction flow into human-readable investigator notes.
- **Request Body:**
```json
{
  "address": "0x71C836643F37711fa49b560Ab95360E6533c7F9E",
  "riskScore": 75,
  "triggeredRules": ["RULE_FUND_SPLITTING", "RULE_RAPID_MOVEMENT"],
  "lastTraceablePoints": ["0xVASP_APEX_DEPOSIT_888"]
}
```
- **Response `200 OK`:**
```json
{
  "aiSummary": "Target wallet exhibited high-speed fund splitting across 3 downstream hops. Fund trail terminates at ApexExchange deposit address.",
  "isFallback": false
}
```

---

### 2.6 Generate Investigation Report
- **Endpoint:** `POST /api/report/generate`
- **Purpose:** Compiles the complete investigation dossier for printing, PDF export, or saving.
- **Request Body:**
```json
{
  "address": "0x71C836643F37711fa49b560Ab95360E6533c7F9E"
}
```
- **Response `200 OK`:** `InvestigationReport` object.

## 3. Standard Error Response
All API errors return a uniform structure:

```json
{
  "timestamp": "2026-09-02T21:55:00Z",
  "status": 400,
  "error": "Bad Request",
  "message": "Invalid Ethereum address format. Address must be 42 characters starting with '0x'.",
  "path": "/api/wallet/invalid-address/transactions"
}
```
